01 / Computer networks

Source: PDF page 2 · definitions, topology questions and network devices.

What is a LAN, MAN and WAN?
  • LAN (Local Area Network): connects devices across a small area, such as a school or office building.
  • MAN (Metropolitan Area Network): connects networks across a city or metropolitan area.
  • WAN (Wide Area Network): spans a large region; the internet is a familiar example.
Expand HTTP, GSM, CDMA and modem.
  • HTTP: Hypertext Transfer Protocol.
  • GSM: Global System for Mobile Communications.
  • CDMA: Code Division Multiple Access.
  • Modem: modulator–demodulator; converts digital signals for an analogue communication channel and converts received signals back.
What is network topology?

The physical or logical arrangement of devices and their connections in a network. Common examples are star, bus and ring topologies.

The PDF asks this question but does not supply its answer; this is an added study answer.

Give two advantages and two disadvantages of a topology. added example

Star topology: each device connects to a central switch or hub.

  • Advantages: easy to add or remove devices; one cable failure usually affects only that device.
  • Disadvantages: failure of the central device can stop the network; more cabling is needed than in a simple bus layout.

The source does not name a specific topology. If your question names bus or ring, answer for that topology instead.

Short notes: repeater, bridge, hub, bandwidth and router.
  • Repeater: regenerates a weak signal to extend a network connection.
  • Bridge: connects network segments and forwards frames using MAC addresses.
  • Hub: sends incoming data to all its connected ports.
  • Bandwidth: a communication channel’s capacity to carry data, commonly expressed in bits per second.
  • Router: connects different networks and forwards packets using IP addresses.

02 / SQL and DBMS basics

Source: PDF pages 1, 6–8.

What is SQL? Name its two main command categories.

SQL (Structured Query Language) is used to define, query and manage data in relational databases. DDL (Data Definition Language) defines or changes database structures: CREATE, ALTER, DROP. DML (Data Manipulation Language) works with stored data: INSERT, UPDATE, DELETE; many school texts also group SELECT here, though some distinguish it as DQL.

What is a data type? List common SQL types.

A data type states what kind of value a column stores. Common types include INTEGER/INT and SMALLINT (whole numbers), NUMERIC(p,s) (exact numeric value with precision and scale), CHAR(n) (fixed-length text), VARCHAR(n) (variable-length text), DATE, TIME, TIMESTAMP (date and time), and BOOLEAN (true, false or unknown/NULL).

NUMERIC(5,2) can store a value such as 332.32: five total digits, two after the decimal point.

How is a user-defined SQL domain created?

With CREATE DOMAIN, where supported:

CREATE DOMAIN Vchar AS VARCHAR(15);

Source: PDF page 7. SQL dialects differ; this syntax is not supported by every DBMS.

Why are constraints used? Name five.

Constraints help maintain data integrity. PRIMARY KEY uniquely identifies a row and cannot be NULL; FOREIGN KEY links to a candidate/primary key in another table; UNIQUE prevents duplicate non-NULL values according to the DBMS’s NULL rules; CHECK requires a condition to hold; NOT NULL requires a value.

PRIMARY KEY (ISBN)
FOREIGN KEY (P_ID) REFERENCES PUBLISHER(P_ID)
UNIQUE (Phone)
CHECK (Price > 20)

03 / Commands to remember

Source: PDF pages 3–5 and 7–8; duplicate passages consolidated.

Explain CREATE TABLE and DESCRIBE (DESC).

CREATE TABLE defines a new table, its columns, data types and optional constraints. DESCRIBE or DESC shows an existing table’s structure in systems such as MySQL.

CREATE TABLE BOOK (
  ISBN VARCHAR(15) PRIMARY KEY,
  Book_title VARCHAR(50),
  Price NUMERIC(6,2)
);
DESCRIBE BOOK;

The PDF uses a longer BOOK example; this is shortened for quick recall. DESC is DBMS-specific, not universal standard SQL.

Write DDL for PUBLISHER and BOOK with keys.

Create the referenced PUBLISHER table before BOOK.

CREATE TABLE PUBLISHER (
  P_ID VARCHAR(4) PRIMARY KEY,
  P_name VARCHAR(50) NOT NULL,
  Address VARCHAR(150),
  State VARCHAR(15),
  Email VARCHAR(20),
  Phone VARCHAR(30)
);
CREATE TABLE BOOK (
  ISBN VARCHAR(15) PRIMARY KEY,
  Book_title VARCHAR(50) NOT NULL,
  Category VARCHAR(20),
  Price NUMERIC(6,2),
  Copyright_date NUMERIC(4),
  Year NUMERIC(4),
  P_ID VARCHAR(4) NOT NULL,
  FOREIGN KEY (P_ID) REFERENCES PUBLISHER(P_ID)
);

Adapted from PDF page 5; Copyright_date is left as a four-digit numeric year to match the other examples. If it means a full date, use DATE instead.

Explain ALTER TABLE, DROP TABLE and SELECT.
  • ALTER TABLE changes an existing table’s structure, e.g. adds a column.
  • DROP TABLE removes a table and its stored data; use with care.
  • SELECT retrieves columns/rows matching a query.
ALTER TABLE BOOK ADD Edition VARCHAR(20);
SELECT Book_title, Price FROM BOOK;
DROP TABLE BOOK;

The PDF asks this on page 5 but the supplied answer stops mid-example; these brief answers and examples are editorial additions. Syntax for changing a column varies by DBMS.
